# The Chairman

A browser-based football ownership and chairman simulation.

## Direction
- You own the club and set its direction.
- Managers run the football side, but you control the environment they operate in.
- Finance, transfers, facilities, reputation, board pressure, supporters and long-term strategy all matter.
- Fictional clubs, players and competitions are used during development.
- No frameworks, paid APIs or external runtime services are required for the GitHub Pages prototype.

## Run
Use GitHub Pages or a local web server. Do not double-click `index.html` because the app loads JSON with `fetch()`.

```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.

## Visual assets
The current build intentionally does **not** use the previously rejected concept image. Put the new approved hero image at:

`assets/chairman-hero.jpg`

The interface will use it automatically as the Chairman HQ hero background.
